TechStart V1
Overview

TechStart V1 is a personal Azure infrastructure project designed to demonstrate secure cloud administration, identity management, private networking, monitoring, backup and recovery capabilities.
Business Requirements

The project was created to address the following challenges:

    Secure storage of sensitive business data
    Centralised administration of Azure resources
    Secure credential management
    Monitoring and alerting
    Backup and recovery validation
    Compliance with regional deployment requirements
    Cost governance and resource governance

Technologies Used

    Microsoft Entra ID
    Azure RBAC
    Azure Virtual Machines
    Azure Bastion
    Azure Key Vault
    Managed Identity
    Azure Storage Account
    Private Endpoint
    Private DNS
    Azure Monitor
    Log Analytics Workspace
    Recovery Services Vault
